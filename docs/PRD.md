# 產品需求文件 (PRD) - 自動化試算引擎 (Automated Calculation Engine)

## 1. 專案概述

### 背景與動機
在大學生涯中，學生需要精確追蹤學分達成情況以確保符合畢業資格。手動計算已修、必修、選修及通識學分既繁瑣又容易出錯。此外，GPA 的計算（包括百分制與等級制的轉換）對於申請獎學金或研究所至關重要。本專案旨在提供一個直觀、自動化的計算引擎，協助學生輕鬆管理學業進度。

### 目標用戶
- 大專院校學生
- 學術顧問與導師

### 核心價值主張
- **自動化**：輸入成績與學分後，系統自動分類並加總。
- **靈活性**：支援 4.0 與 4.3 兩種 GPA 計算標準。
- **透明化**：清晰展示距離畢業所需的剩餘學分。

---

## 2. 功能需求

### 2.1 學分紀錄管理
- **使用者故事**：作為一名學生，我希望能夠新增我的課程紀錄（包括課程名稱、學分數、類別、修習狀態），以便系統進行追蹤。
- **功能點**：輸入介面需包含課程名稱、學分、類別（必修/選修/通識）、狀態（已完成/修習中/待修習）。

### 2.2 自動學分加總
- **使用者故事**：作為一名學生，我希望系統能自動分類並加總我的學分，以便我了解各類別的達成率。
- **功能點**：統計頁面應顯示已完成、修習中與待修習的總學分。

### 2.3 GPA 試算與轉換
- **使用者故事**：作為一名學生，我希望輸入我的課程成績後，系統能自動計算 GPA，以便我了解目前的學術表現。
- **功能點**：
    - 支援百分制（0-100）輸入。
    - 支援等級制（A+, A, B...）輸入。
    - 支援 4.0 與 4.3 兩種標準的切換顯示。

### 2.4 畢業進度追蹤
- **使用者故事**：作為一名學生，我希望設定畢業所需的學分要求，以便系統提醒我還缺多少學分。
- **功能點**：自定義各類別（必修、選修、通識等）的畢業門檻，並顯示進度條。

### 2.5 數據持久化
- **使用者故事**：作為一名書生，我希望我的資料能被儲存，以便我下次登入後能繼續編輯。
- **功能點**：使用 SQLite 儲存使用者輸入的課程與成績數據。

---

## 3. 非功能需求

### 技術限制
- **後端框架**：Flask
- **模板引擎**：Jinja2
- **資料庫**：SQLite
- **前端風格**：Vanilla CSS (現代、簡潔、Premium)

### 效能與安全考量
- 響應式設計，確保在手機與電腦上都能流暢使用。
- 資料輸入驗證，防止非法字元或數值（如學分負數）。
